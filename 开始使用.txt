时光集 1.28.1 · Windows 便携版使用说明

一、发给别人
发送文件名含 windows-x64-portable 的原始 ZIP 包即可。
该包适用于 Windows 10 / 11 的 Intel、AMD 64 位电脑。
包内已有 Python，不需要安装 Python、Node.js 或 Codex。
它不是 macOS、Linux、手机或 ARM64 原生版本。
文件名不含 portable 的源码 ZIP 仍需要另装 Python 3.10 或更新版本。

二、第一次使用
1. 右键 ZIP → 全部解压，放到自己选择的、有写入权限的固定目录；盘符和名称可自定。
   不要在压缩包内直接运行，不要只复制其中的启动文件。
2. 双击“启动工具.cmd”，等待浏览器自动打开本机页面。
3. 选择 X / Twitter 或 Instagram，输入用户名，再点“开始查找与下载”。
4. 可选：双击“创建桌面快捷方式.cmd”。以后从桌面“时光集”进入。
   快捷方式不设置 Windows 登录启动；后台仍按需运行。
5. 找以前的博主：点左侧“查找博主与历史任务”，搜索用户名、已核实旧名或数字 ID。
   可按平台和状态筛选，再点“打开合集”。
6. 继续旧任务：筛选“暂停、中断或失败”，点“继续此任务”或“重试此任务”。
   已保存内容会保留，代理使用当前设置；其他暂停的队列项目不会一起启动。
   只打包失败时点“重新生成 ZIP”。当前运行中的任务需先结束或暂停并保存。
   旧版只补录现存记录，不能还原已覆盖的历史；此后网页任务会持续保存记录。

三、暂停和退出
关闭浏览器后，后台任务继续运行。
暂停采集：网页中选择“暂停并保存”。
退出后台：双击“停止后台.cmd”，或桌面的“停止时光集”。
再次打开“启动工具.cmd”可启动后台；暂停的任务需在网页继续。
运行时会尝试阻止自动休眠，手动休眠、合盖或断电仍可能中断任务。

四、数据保存和换电脑
collections 文件夹保存博主合集、数据库、媒体、队列及任务历史记录。
collections-backups 文件夹保存本地恢复备份，迁移时一起保留。
python 文件夹是随包提供的程序运行环境，不要删除。
runtime 文件夹保存启动日志和本机后台状态。
将自己的资料迁移到另一台电脑：先用“停止后台.cmd”正常退出，再复制程序及上述两个数据文件夹。
也可在新电脑解压本版本的空白便携包，再把两个数据文件夹完整复制进去；不需要复制旧 runtime 文件夹。
复制完成后从新位置运行“启动工具.cmd”，必要时重新创建桌面快捷方式。
网盘目标目录、盘符和代理地址需按新设备重新核对，旧设备的设置未必适用。
1.27 及更新版本可直接读取压缩网页和压缩备份对象，不需要手工解压这些文件。
1.26 及更早版本不能直接读取新压缩格式，迁移时请使用本版本或更新版本。
快捷方式和网页书签不能代替程序文件，也不随文件夹迁移。
不要用运行过的整个文件夹当作空白分享包，以免附带你的合集和日志。
仅分享浏览结果：网页中“下载合集”，对方解压后打开 index.html 即可。

五、常见问题
页面提示未启动：从“启动工具.cmd”或桌面快捷方式进入，等待打开正确端口。
窗口显示缺少 Python：确认解压的是 portable 包，且 python 文件夹完整。
程序报错：窗口会保留错误，详细日志在 runtime 文件夹。
已有另一份时光集运行：先用那一份的“停止后台.cmd”退出，再启动新位置。
已有其他目录的桌面快捷方式或协议：创建工具会报告冲突，不会自动替换。
这种情况下仍可直接使用新目录的“启动工具.cmd”，不要混用两份程序。
创建快捷方式后请保持程序目录固定，以免入口失效。
归档依赖设备能访问公开来源；如需代理，在高级设置填写这台设备的实际地址。
找到帖子不等于恢复原文件；未被存档或不可访问的媒体可能无法恢复。

网盘或外部目录备份
------------------
在“运行保护与备份”启用“同时备份到同步或挂载目录”，填写专用空目录的绝对路径。
可用网盘同步文件夹、挂载盘、网络共享或外接盘；不限客户端、盘符、卷名和文件夹名称。
目标的上级目录必须已存在，程序只会新建最后一级专用文件夹。
先在所用客户端登录、连接，并确认能正常读写，再保存设置。
工具按本地备份索引复制恢复包，不直接登录网盘；普通本地目录不会自动上传。
目录中的 .shiguangji-backup.json 用于核对目标身份，不要删除。
标识丢失或不一致时停止写入；检查挂载和同步状态，需要新目标时选择另一个专用空目录。
“已复制并校验”仅表示目标目录读回通过，请在客户端或服务端另行确认实际上传完成。

节省本地空间
------------
下载 ZIP 默认在点击“生成下载包”后生成，浏览和归档照常使用。
新增 X、Instagram 用户及旧用户后续新增的历史网页自动无损压缩；图片和视频保留原件。
已有普通网页可点击“无损压缩历史网页”一次整理，包含本地备份中的网页对象。
压缩逐文件校验后替换；可点击“暂停压缩”，中断后重新点击可继续。很小或压缩无收益的文件会保持普通格式。
展开“本地空间与网盘试读”，先预览可释放的旧 ZIP，再核对清单并确认。
此操作保留媒体、数据库、离线页面和恢复备份；以后下载需重新打包。
网盘试读是独立测试，首次需要完整文件缓存并校验，原始文件仍保留。
试读通过不代表网盘服务端已收到完整备份；不要据此手动删除原件。
内置 Python 3.14.8 x64，来源为 python.org 官方 Windows 嵌入式包。
Python 及其随附组件的许可说明保留在 python\LICENSE.txt。
portable.json 记录运行包来源和原始校验值，release.json 记录每个发布文件的校验值。
更完整的功能和限制见 README.md；版本变化见 CHANGELOG.md。

七、可选视频组件
需要恢复视频分片时，双击“安装视频组件.cmd”，等待下载校验完成。标准便携包不预装 FFmpeg；无需视频分片恢复时可跳过。来源冷却后会自动延后重试，最多 3 轮、48 小时；暂停或关闭后台后不会自行采集。
